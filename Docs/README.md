## The research lifecycle

```text
Sources
  → Evidence records
  → Structured cyber history
  → Research questions and hypotheses
  → Forecasts with an information cutoff
  → Evaluation against baselines
  → Outcomes, corrections, and lessons
```

## Evidence conventions

When documenting research:

1. Link important claims to a source that a reader can inspect.
2. Record the source's publication date and, when relevant, the date the information became publicly available.
3. Distinguish observed facts, source-reported claims, analyst interpretation, model inference, and unresolved questions.
4. Do not fill gaps with assumptions. Mark unknown fields as unknown.
5. Preserve the original forecast and record later assessments as separate updates.
6. Use only authorized, controlled environments for active technical experiments.

## Implementation status

The documentation describes CEI's intended methodology and long-term architecture. Structured datasets, automated validation, forecasting models, and evaluation tooling should be treated as implemented only when the corresponding code, tests, and reproducible results are present.
