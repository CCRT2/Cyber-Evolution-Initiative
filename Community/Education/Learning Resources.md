# 🛠️ Learning Resources

## 1. TryHackMe

A hands-on learning platform with guided cybersecurity paths, interactive labs, and real-world scenarios for beginners through advanced learners. Great for both offensive and defensive security.

---

## 2. PortSwigger Web Security Academy

A free, comprehensive resource for learning web application security through detailed lessons and interactive labs covering topics from the OWASP Top 10 to advanced exploitation techniques.

---

## 3. OverTheWire

A collection of free wargames that teach Linux, networking, scripting, and security fundamentals through progressively challenging exercises. Recommended for beginners building foundational skills.

---

## 4. Hack The Box

A popular platform offering realistic vulnerable machines, labs, and Academy modules for penetration testing, red teaming, and offensive security practice. Best suited for intermediate and advanced learners.

---

## 5. CyberDefenders

A blue team training platform featuring digital forensics, incident response, SOC investigations, malware analysis, and threat hunting challenges based on real-world scenarios.
